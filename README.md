# qwen-image-rocm

Qwen-Image-2.1 image generation on **AMD Radeon RX 7900 XTX** under
**Windows-native ROCm** — reproducible baselines (diffusers + ComfyUI),
optimization experiments, and public evidence for the ROCm-on-Windows
ecosystem.

## Mission

1. Push image-generation throughput of ComfyUI + Qwen-Image-2.1 on the
   7900 XTX to its limit, with no or only slight quality loss.
2. Use this real workload to surface ROCm-on-Windows problems: every issue
   gets root-cause analysis, a minimal reproducer, a fix, and an upstream
   PR (see `docs/issues/`).

**Status: Phase 1 in progress** (diffusers baseline). See the
[design document](docs/specs/2026-10-30-qwen-image-2.1-rocm-7900xtx-design.md)
for the full plan.

## Setup

Prerequisites: Windows 11, AMD Radeon RX 7900 XTX (gfx1100), up-to-date
Adrenalin driver, [uv](https://docs.astral.sh/uv/), git.

The "stranger standard" one-command reproduction (30-minute bar):

```powershell
.\reproduce.ps1 -Quick    # one config: p2-en-scene, 1024², 40 steps, seed 42
.\reproduce.ps1 -Full     # the whole Phase 1 protocol (~1.5–3 h)
```

It creates an isolated `.venv-repro`, installs the pinned AMD ROCm stack,
smoke-tests HIP, downloads weights from ModelScope (~30 GB, once), and runs.

Manual equivalent (what `reproduce.ps1` automates):

1. `uv venv phase1-diffusers/.venv --python 3.12 --seed`
2. Install torch **only** with the mandated AMD wheel command (verbatim):
   ```
   python -m pip install --index-url https://repo.amd.com/rocm/whl-multi-arch/ "torch[device-gfx1100]==2.12.0+rocm7.14.1" "torchvision[device-gfx1100]==0.27.0+rocm7.14.1" "torchaudio==2.11.0+rocm7.14.1"
   ```
3. `python -m pip install -r phase1-diffusers/requirements.txt`
4. `modelscope download --model Qwen/Qwen-Image-2.1 --local_dir weights/diffusers-format`
5. `python -I phase1-diffusers/smoke_hip.py` (must report `gcn_arch=gfx1100`)

Environment evidence for every result lives in `bench/results/env/`
(generated by `tools/snapshot_env.py`). The exact frozen dependency set is
`phase1-diffusers/requirements.lock.txt` (pip freeze; the ROCm stack is not
on PyPI, so the lock is AMD-wheel-index specific).

## Benchmark protocol

Frozen in [`bench/prompts.json`](bench/prompts.json): 3 prompts
(Chinese scene / English scene / text-rendering poster) × 2 resolutions
(1024², 2048²) × 40 steps × seeds `[42, 1337, 20261030]`. Results are
JSON (schema: `bench/schema/result.schema.json`) + a Markdown report with
medians, spread, and limitations.
